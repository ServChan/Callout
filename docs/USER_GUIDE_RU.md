## Что делает мод

Callout следит за чатом и подаёт звук, когда в сообщении встречается ваш ник или заданное слово. Все такие сообщения («пинги») сохраняются в историю вместе с несколькими сообщениями до и после, поэтому, вернувшись к игре после AFK, вы видите, кто и зачем вас звал.

- Ник и любые слова, обычным текстом или регулярными выражениями.
- Свой звук, громкость и тон для каждого триггера.
- Окно истории с поиском, контекстом, фильтром по серверу и сортировкой.
- Клик по нику в истории открывает чат с готовой командой личного сообщения.

Мод работает только у вас: ничего не отправляет на сервер и сервером не замечается.

Длинная история чата и возврат чата после перезахода раньше были в Callout, а с версии 1.1.1 живут в [QualityEssentials](https://github.com/ServChan/QualityEssentials). Старую папку `config/callout_sessions/` можно удалить.

## Установка

1. Установите [Fabric Loader](https://fabricmc.net/use/installer/) `0.19.3` или новее для Minecraft 26.3.
2. Положите в папку `mods` [Fabric API](https://modrinth.com/mod/fabric-api) для 26.3.
3. Положите в `mods` файл `callout-1.1.2.jar` (как собрать — в разделе [Сборка](#сборка-из-исходников)).
4. Рекомендуется [Mod Menu](https://modrinth.com/mod/modmenu): настройки открываются только через него.

Нужна Java 25.

## Первые шаги

1. Зайдите на сервер. Ваш ник уже отслеживается: основной триггер по умолчанию пустой, а пустое слово означает «мой ник».
2. Попросите кого-нибудь написать ваш ник в чат — прозвучит звук.
3. Нажмите `'` (апостроф), чтобы открыть историю пингов.
4. Чтобы добавить свои слова (имя клана, «админ», «помогите»), откройте настройки через Mod Menu.

Свои сообщения по умолчанию не считаются: если вы напишете свой ник сами, звука не будет, а мод подскажет, где это включить.

## Триггеры

### Основной триггер

Ваш ник. Если поле «Слово» пустое, мод подставляет ник текущего аккаунта. Можно вписать другой ник или шаблон.

### Дополнительные триггеры

Кнопка «Добавить» создаёт новый триггер. У каждого:

| Поле | Что значит |
|---|---|
| Слово | текст или регулярное выражение |
| Режим | «Текст» — ищется как есть; «Regex» — регулярное выражение Java |
| ID звука | звук Minecraft, например `minecraft:block.note_block.pling` или `minecraft:entity.experience_orb.pickup` |
| Громк. | от 0 до 4 |
| Тон | от 0,5 до 2 |

«Удалить» убирает триггер. Триггеров на экране помещается немного, остальные листаются страницами.

Примеры регулярных выражений:

- `(?U)\bадмин\w*` — «админ», «админы», «Админа»;
- `(?U)\b(help|помогите)\b` — любое из двух слов;
- `^\[Клан\]` — сообщения, начинающиеся с `[Клан]`.

Флаг `(?U)` нужен, если в выражении есть `\b` или `\w` и русские буквы: без него Java не считает кириллицу буквами. Регистр и без флага не учитывается, пока выключено «Учитывать регистр».

Неверное выражение подсвечивается ошибкой, и сохранить настройки не получится, пока его не исправить.

### Что проверяется

- Текст сообщения очищается от служебных значков других модов (например, ChatHeads).
- В одиночной игре и по LAN отбрасывается технический префикс отправителя, чтобы ваши же сообщения не считались пингом.
- Регистр по умолчанию не учитывается — и для текста, и для регулярных выражений.

## История пингов

Открывается клавишей `'` (апостроф, меняется в **Настройки → Управление → Callout**).

- Каждый пинг показан с номером, временем, отправителем и триггером, а под ним — сообщения до и после.
- **Поиск** по тексту вверху окна.
- **Фильтр «Мир»**: все или только конкретный сервер/мир — удобно, чтобы разобрать пинги последней сессии.
- **Сортировка**: новые сверху или старые сверху.
- **Клик по нику** открывает чат с командой `/msg <ник> ` (шаблон меняется в файле настроек).
- **Клик по строке** копирует её текст в буфер обмена.
- «Назад», «Далее» и колесо мыши листают страницы.
- «Очистить» удаляет историю после повторного подтверждения («Точно?»).

## Настройки

Экран открывается через **Mod Menu → Callout → значок настроек**. «Сохранить» применяет, «Отмена» закрывает без сохранения.

| Настройка | По умолчанию | Что делает |
|---|---|---|
| Включен | вкл. | главный выключатель |
| Учитывать регистр | выкл. | различать «Ник» и «ник» |
| Свои сообщения | выкл. | срабатывать и на ваши собственные сообщения |
| Основной триггер | ваш ник, звук `block.note_block.pling`, громкость 1, тон 1 | см. выше |
| Дополнительные триггеры | нет | свои слова и выражения |
| Макс. пингов | 100 | сколько пингов хранить, от 1 до 1000 |
| До / После | 5 / 5 | сколько сообщений контекста хранить вокруг пинга, от 0 до 20 |
| Сохранять историю | вкл. | хранить историю между запусками игры |
| Очищать при смене мира | выкл. | стирать историю при переходе на другой сервер или мир |

Только в файле `config/callout.json`:

| Ключ | По умолчанию | Что делает |
|---|---|---|
| `whisperCommand` | `/msg %s ` | команда, которая открывается при клике по нику; `%s` заменяется ником |
| `separateHistoryByWorld` | `false` | при `true` миры за одним адресом сервера получают отдельную историю (по точке спавна) |

## Файлы

- `config/callout.json` — настройки.
- `config/callout_history.json` — история пингов.

Обе записи атомарные, рядом хранятся резервные копии `.bak`, из которых мод восстанавливает данные, если основной файл повреждён.

## Частые вопросы

**Звука нет, хотя ник написали.** Проверьте, что мод включён и вы не тестируете на своём же сообщении (по умолчанию свои не считаются). Проверьте общую громкость в настройках звука игры и громкость самого триггера.

**Срабатывает на чужие ники, похожие на мой.** Используйте режим Regex с границами слова: `(?U)\bМойНик\b`.

**Нужен другой звук.** Впишите ID любого звука Minecraft, например `minecraft:entity.player.levelup`. Список ID есть в игре: команда `/playsound` подсказывает их.

**История пустая после перезапуска.** Проверьте, что «Сохранять историю» включено.

**Где длинная история чата?** Её перенесли в [QualityEssentials](https://github.com/ServChan/QualityEssentials), раздел «Чат».

## Сборка из исходников

Нужна JDK 25.

```powershell
git clone https://github.com/ServChan/Callout.git
cd Callout
.\gradlew.bat build
```

На Linux и macOS используйте `./gradlew`. Готовый файл: `build/libs/callout-1.1.2.jar`.
